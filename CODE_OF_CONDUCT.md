Code of Conduct

Our Commitment

We are committed to maintaining a respectful, inclusive, and scientifically rigorous environment for collaboration.

---

Expected Behavior

Participants are expected to:

- Engage in evidence-based discussion
- Critique ideas, not individuals
- Respect methodological boundaries
- Maintain academic integrity

---

Unacceptable Behavior

The following are not tolerated:

- Personal attacks or harassment
- Misrepresentation of simulation results
- Presenting speculative constructs as empirical fact
- Disruptive or bad-faith engagement

---

Enforcement

Project maintainers may remove, edit, or reject contributions that violate this code of conduct.

---

Scope

This code applies to all repository spaces, including issues, pull requests, and discussions.

---

Reporting

Concerns may be raised via GitHub Issues or direct contact with the project maintainer.

---

Attribution

This Code of Conduct is adapted for research-oriented open-source projects.
