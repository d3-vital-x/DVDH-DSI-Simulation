Contributing to DVDH–DSI–Simulation

Thank you for your interest in contributing to the Dark Vital Dimensional Hypothesis (DVDH) — DSI Simulation Framework.

This repository is a research-grade simulation environment. Contributions are welcome provided they adhere to the scientific and methodological standards outlined below.

---

Scope of Contributions

We welcome contributions in the following areas:

- Numerical solvers and simulation stability improvements
- Statistical inference (MCMC, diagnostics, null-model testing)
- Mathematical consistency checks and dimensional analysis
- Documentation improvements and clarity enhancements
- Unit tests for simulation thresholds and invariants

We do not accept speculative extensions presented as empirical claims.

---

Contribution Standards

All contributions must:

1. Be clearly scoped (simulation, inference, or documentation)
2. Preserve mathematical consistency
3. Avoid unverified physical claims
4. Include comments explaining assumptions
5. Not weaken existing null-model controls

---

Code Style

- Python ≥ 3.9
- Explicit variable naming
- No hidden global state
- Deterministic outputs where possible

---

Pull Request Checklist

Before submitting a PR, ensure:

- [ ] Code runs without errors
- [ ] Existing tests pass
- [ ] New logic is documented
- [ ] No claims exceed simulation scope

---

Review Process

All submissions are reviewed for:

- Numerical correctness
- Conceptual consistency
- Reviewer-facing clarity

Maintainers reserve the right to reject contributions that blur the boundary between simulation and empirical claim.
